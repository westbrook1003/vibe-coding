### 分层约定

| 层 | 职责 | 禁止 |
| --- | --- | --- |
| `controller` | 路由、参数校验（DTO）、鉴权注解 | 写业务逻辑 |
| `service` | 业务规则、事务、权限校验 | 直接接触 `Request` |
| `entity` | 表结构与关系 | 写业务逻辑 |
| `dto` | 入参定义 + 校验规则 | 出参定义 |

### 命名约定

| 类型 | 规则 | 示例 |
| --- | --- | --- |
| 页面组件 | `XxxView.vue` | `ItemListView.vue` |
| 通用组件 | `Xxx.vue` / `BaseXxx.vue` | `BaseModal.vue` |
| 接口函数 | `xxxApi` 对象 | `itemApi` |
| 组合式函数 | `useXxx` | `usePinyin` |
| 状态仓库 | `useXxxStore` | `useAuthStore` |
| 类型 | 放在 `types/index.ts`，不加 `I` 前缀 | `Item` |

### 路由与菜单

菜单由 `AppLayout.vue` 驱动，与 `router/index.ts` 中的 `name` 一一对应：

| 菜单 | 路由 name | 路径 | 权限 |
| --- | --- | --- | --- |
| 物资入库 | `inbound-create` | `/inbound/new` | 登录 |
| 物资出库 | `outbound-create` | `/outbound/new` | 登录 |
| 库存总览 | `dashboard` | `/dashboard` | 登录 |
| 入库记录 | `inbound-list` | `/inbound` | 登录 |
| 出库记录 | `outbound-list` | `/outbound` | 登录 |
| 物资档案 | `item-list` | `/items` | 登录 |
| 出库对象 | `receiver-list` | `/receivers` | 登录 |
| 人员信息 | `user-list` | `/users` | **admin** |

「人员信息」菜单仅在 `auth.isAdmin` 为真时渲染，同时路由 meta 声明 `roles: ['admin']`，
双重保险：普通用户即使手动输入 URL 也会被守卫拦到 `/forbidden`。
