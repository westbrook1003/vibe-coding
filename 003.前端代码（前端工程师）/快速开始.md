# 快速开始 · 手把手启动指南

> 目标：在浏览器里看到并操作物资系统的页面。

---

## 方式一：一键启动（推荐，30 秒）

### 第 1 步：关掉旧进程

你的电脑上还留着我调试时启动的服务（占用 3000 / 5173 端口）。**先双击：**

```
003.前端代码（前端工程师）\停止.bat
```

看到「已全部关闭」即可。

### 第 2 步：启动

双击：

```
003.前端代码（前端工程师）\启动.bat
```

它会自动做这些事：

| 自动完成 | 说明 |
| --- | --- |
| 检查 Node.js | 没装会提示下载地址并退出 |
| 安装依赖 | 首次运行才装，你机器上已装好会跳过 |
| 生成 `.env` | 同上，已有就跳过 |
| 初始化数据库 | 同上，已有就跳过 |
| 拉起后端 | 新开一个黑窗口，标题 `MaterialSystem-Backend` |
| 拉起前端 | 新开一个黑窗口，标题 `MaterialSystem-Frontend` |
| 打开浏览器 | 自动跳到 http://localhost:5173 |

### 第 3 步：登录

| 账号 | 密码 |
| --- | --- |
| `admin` | `admin` |

> ⚠️ **首次登录会强制跳转到「修改密码」页**，这是 PRD F1.1 的要求。改完密码后，以后就用新密码登录。

## 方式二：手动命令行启动

如果你更习惯敲命令，或者想看实时日志。

### 第 1 步：打开两个命令行窗口

在文件夹地址栏输入 `cmd` 回车，或用 VS Code 的终端（Ctrl + `）。

### 第 2 步：窗口 A —— 启动后端

```bash
cd 003.前端代码（前端工程师）
npm run dev:backend
```

看到这两行就算成功：

```
🚀 物资系统后端已启动：http://localhost:3000/api
📖 接口文档：http://localhost:3000/api-docs
```

### 第 3 步：窗口 B —— 启动前端

**另开一个**命令行窗口：

```bash
cd 003.前端代码（前端工程师）
npm run dev:frontend
```

看到这行就算成功：

```
➜  Local:   http://localhost:5173/
```

### 第 4 步：浏览器打开

访问 **http://localhost:5173**

> ❗ 不要打开 `frontend/dist/index.html`。那是生产构建产物，需要服务器托管才能跑，直接双击会白屏。

## 常见问题

### Q1 端口被占用

```
Port 5173 is in use, trying another one...
```

说明有旧进程占着端口。**双击 `停止.bat`** 再重新启动；或者直接用它提示的新端口号（5174）。

### Q2 前端打开是白屏

按顺序排查：

1. 后端窗口还在吗？关了就重启它。
2. 地址是 `http://localhost:5173` 吗？（不是 `dist/index.html`，也不是 `file://`）
3. 浏览器按 `Ctrl + Shift + R` 强制刷新。

### Q3 登录提示"登录已失效，请重新登录"

后端重启过，token 失效了 —— 重新登录即可。

### Q4 端口 3000 也被占用

后端起不来。改端口：编辑 `backend/.env` 里的 `PORT=3000` 改成别的（如 3010），
同时改 `frontend/.env.development` 里的 `VITE_API_TARGET=http://localhost:3010`，
然后重启两个服务。

### Q5 想重置数据库

```bash
cd 003.前端代码（前端工程师）
npm run db:recalc      # 按流水重算结存，校验库存一致性
npm run seed           # 重新灌演示数据
```
