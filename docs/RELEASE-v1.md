## 物资出入库管理系统 · 首个版本

一个轻量的物资出入库记录工具 —— **用拼音码快速录入物资的进与出，随时查到还剩多少。**

### 本次交付

| 目录 | 内容 |
| --- | --- |
| `001.产品PRD（产品经理）/` | 产品需求文档 v1.0：登录与账号、物资产品维护、拼音码快速出入库、出库对象、人员信息维护（仅 admin）、库存查询 |
| `002.产品UI原型（美术设计）/` | 12 个页面高保真原型，纯静态零依赖，双击 `index.html` 即可浏览 |
| `003.前端代码（前端工程师）/` | 可运行的全栈工程：前端 Vue 3 + Vite + TypeScript；后端 NestJS + TypeORM + JWT；数据库 SQLite（可切 MySQL） |

### 技术栈

- **前端** Vue 3 · Vite 6 · TypeScript · Vue Router · Pinia · Axios · ESLint
- **后端** NestJS 10 · TypeORM · Passport-JWT · Swagger
- **数据库** SQLite 3（默认，零配置）/ MySQL 8（改 `.env` 的 `DB_TYPE` 即可切换）

### 快速开始

```bash
cd 003.前端代码（前端工程师）
npm run dev:backend     # http://localhost:3000/api   接口文档 /api-docs
npm run dev:frontend    # http://localhost:5173
```

初始账号 `admin` / `admin`（首次登录强制改密）。Windows 下也可直接双击 `启动.bat` 一键启动。

### 核心设计

- **拼音码** —— 一个字段可存多个码（`wxsb,wsm`），任一码都能检索到该物资；不校验唯一，多结果由用户选择
- **结存实时** —— 结存 = Σ入库 − Σ出库，写记录与改结存在同一事务内完成
- **历史不可篡改** —— 出入库记录只增不改不删，并保存品名/单价/平台等快照，改档案不影响历史
- **越权拦截** —— 出库数量超过结存直接阻断，并返回精确差额

### 已知边界

- 本版本不包含：审批流、成本核算、批次效期、附件上传、电商平台 API 对接、Excel 导入导出
- 找回密码的验证码保存在服务端内存，尚未接入邮件服务
- 工程暂无自动化测试套件，`lint` + `typecheck` + `build` 为当前验证手段
