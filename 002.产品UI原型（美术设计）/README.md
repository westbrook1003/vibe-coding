# 物资系统 · UI 原型

> 对应《物资系统-产品需求文档 PRD v1.0》（`../001.产品PRD（产品经理）/物资系统-产品需求文档PRD-v1.0.md`）

## 怎么看

**双击 `index.html`** 即可。全部是静态 HTML + 原生 JS，无构建、无依赖、无需服务器。

推荐用 Chrome / Edge 打开，然后按 `F12` 切换设备模拟，选择 **iPhone / 375px** 宽度查看移动端形态。

## 设计规范摘要

- **主色** `#2a78d6`；强调色块底色 `#1c5cab / #d95926 / #10875c`（白字对比度均 ≥ 3:1）
- **表面** 卡片 `#fcfcfb`、页面底板 `#f4f4f1`；**墨色** `#0b0b0b / #52514e / #898781`
- **状态色** 正常 `#0ca30c`、警告 `#fab219`、错误 `#d03b3b` —— 固定不参与分类轮换，且**始终与文字标签同时出现**，不以颜色单独承载语义
- **字体** `system-ui / 微软雅黑 / 苹方`；表格数字用 `tabular-nums` 对齐，大号数字用比例数字
- **圆角** 7px（控件）/ 10px（按钮）/ 14px（卡片）
- **深色模式** 跟随系统 `prefers-color-scheme`，深色不是浅色的自动反转，而是单独取色并校验

> 配色取自经 `validate_palette.js` 六项检查通过的默认调色板：明暗两种模式下**全部 PASS**（CVD ΔE ≥ 8，正常视觉 ΔE ≥ 15）。

## 已知边界

- 拼音码由内置字表近似生成（`app.js` 顶部 `PY` 表），真实实现需接 `pinyin4j` / `pinyin-pro`；
- 所有数据为前端假数据，刷新即重置；
- 移动端仅保证「能记一笔」，为简化布局在小屏隐藏了侧边栏。
