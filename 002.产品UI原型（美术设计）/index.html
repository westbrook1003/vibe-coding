Web 后台 中文界面 支持深色模式 响应式 · ≥375px

组件状态

按钮 / 徽标 / 输入框 / 提示条

按钮

高度 34px（小号 28px，大号 42px），圆角 7px；主按钮用于页面唯一主动作，禁用态透明度 45%。

徽标 / 状态

管理员 启用 停用 超库存 普通

状态色固定不参与分类轮换，且始终与文字标签同时出现，不以颜色单独承载语义。

输入框

高度 38px，失焦即校验；错误态红色描边 + 3px 柔光焦点环，必填项红色星号。

提示条

中性说明：结存 = 累计入库 − 累计出库
警告：出库数量不可超过当前结存
错误：当前结存为 3，超出 2

三种语义各一色，图标 + 文字双通道表达，不依赖颜色单独区分。

关键交互说明

拼音码联想
输入即模糊匹配，↑ ↓ 选择、Enter 选中；唯一匹配时自动选中，多个匹配时下拉列出全部（拼音码不唯一）
连续录入
入库提交后表单清空、焦点回到拼音码框，可不离开页面连续录入下一条
超库存拦截
出库数量输入时实时比对结存，超出即红框提示并置灰提交按钮，同时给出「超出 N」的明确差额
出库对象
下拉选已有对象，或直接输入新名字，提交后自动加入对象列表
键盘操作
Ctrl+Enter 提交，Tab 在数量与单价间跳转，Esc 关闭弹窗
不可变性
出入库记录只读，无编辑与删除入口；有出入库记录的物资与人员不可删除，仅可停用
响应式
≥1280px 完整布局；≤900px 单列；≤720px 隐藏侧边栏，表格转卡片，入出库页保持可用（现场用手机记一笔）
